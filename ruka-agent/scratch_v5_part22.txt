22.3 DESIGN — transisi adalah kontrak, bukan saran
Setiap busur punya NAMA METHOD yang berwenang memicunya. Keluar jalur = IllegalTransition yang
dilempar, dicatat sebagai 'rejected', dan dihitung — karena pola penolakan berulang adalah sinyal bug UI
atau upaya menyelundupkan status.
Prinsip kerjanya tiga kata: tolak, catat, bertahan. TOLAK — transisi tak dikenal tidak dikoreksi diam-diam
('maksudnya sih READY, ya sudahlah') karena koreksi diam adalah cara bug bersembunyi paling awet.
CATAT — setiap penolakan masuk riwayat dengan status asal, status yang dicoba, dan nama pintu; audit
mencari pola, bukan satu kejadian. BERTAHAN — status TIDAK berubah saat penolakan; mesin tidak
bisa dipaksa ke keadaan lain lewat spam.
Aturan penting kedua: DEGRADED tidak punya jalan pintas ke READY. 'Yakin sudah baikan' bukan
transisi — pemulihan harus melewati RECOVERING yang berhasil, atau exit. Ini ketat kelihatannya
sepele, tapi inilah yang mencegah status berkelip-kelip hijau-kuning-hijau saat subsistem menggantung:
penyembuhan pun harus dibuktikan, bukan diharapkan.
22.4 IMPLEMENTATION — mesin status
Satu kelas, satu sumber kebenaran; mengubah status HANYA lewat transition() yang divalidasi.

@dataclass
class RuntimeStateMachine:
    """Penjaga keadaan tunggal runtime.
    Satu sumber kebenaran untuk "Ruka sedang apa"; tray membacanya,
    health membandingkannya, audit mencatatnya. Tidak ada penulis
    kedua: mengubah status HANYA lewat transition() yang divalidasi.
    """
    initial: RuntimeStatus = RuntimeStatus.OFFLINE
    events: list[StateEvent] = field(default_factory=list)
    entered_at: dict[RuntimeStatus, float] = field(default_factory=dict)
    _state: RuntimeStatus = field(default=RuntimeStatus.OFFLINE,
                                  init=False)
    _rejections: int = field(default=0, init=False)
    _clock: object = field(default=time.monotonic, repr=False,
                           init=False)
    def __post_init__(self) -> None:
        self._state = self.initial
        self.entered_at[self._state] = self._clock()
    # ---------------------------------------------------------- baca
    @property
    def state(self) -> RuntimeStatus:
        return self._state
    @property
    def rejections(self) -> int:
        return self._rejections
    def time_in_state(self, now: float | None = None) -> float:
        t = now if now is not None else self._clock()
        return t - self.entered_at.get(self._state, t)
    def is_operational(self) -> bool:
        """Status yang layak menerima tugas (tray hijau)."""
        return self._state in (RuntimeStatus.READY, RuntimeStatus.BUSY,
                               RuntimeStatus.IDLE)
    def snapshot(self) -> dict:
        return {
            "state": self._state.value,
            "operational": self.is_operational(),
            "since": round(self.entered_at.get(self._state, 0.0), 3),
            "seconds_in_state": round(self.time_in_state(), 3),
            "rejections": self._rejections,
        }
    # ---------------------------------------------------------- tulis

    def transition(self, dst: RuntimeStatus, via: str = "",
                   detail: str = "", *, _now: float | None = None
                   ) -> RuntimeStatus:
        """Validasi + jalankan transisi; lempar bila ilegal.
        Penolakan TIDAK diam: ditulis ke events sebagai "rejected"
        dan dihitung — pola penolakan berulang adalah sinyal bug UI
        atau upaya menyelundup status.
        """
        key = (self._state, dst)
        legal_via = LEGAL_TRANSITIONS.get(key)
        if legal_via is None:
            self._rejections += 1
            self.events.append(StateEvent(
                ts=round(self._clock(), 3), kind="rejected",
                from_state=self._state.value, to_state=dst.value,
                via=via, detail=detail or "transisi tak dikenal"))
            raise IllegalTransition(self._state, dst, via)
        # Nama method boleh menyertai untuk audit, tapi BUSUR yang
        # berwenang — via yang tidak cocok dicatat sebagai detail.
        effective = via or legal_via
        mismatch = bool(via and via != legal_via)
        self._state = dst
        now = _now if _now is not None else self._clock()
        self.entered_at[dst] = now
        self.events.append(StateEvent(
            ts=round(now, 3), kind="transition",
            from_state=key[0].value, to_state=dst.value,
            via=effective,
            detail=(detail + ("; via tidak lazim" if mismatch else ""))
            .strip("; ")))
        return self._state
    def reject_count_for(self, dst: RuntimeStatus) -> int:
        return sum(1 for e in self.events
                   if e.kind == "rejected" and e.to_state == dst.value)
    def history(self, limit: int = 50) -> list[dict]:
        return [e.__dict__ for e in self.events[-limit:]]

22.6 HEALTH — liveness bukan readiness
Dua klaim yang mahal bila tertukar. LIVENESS: 'prosesnya masih bernyawa?' — heartbeat segar, event
loop berputar; mati = restart. READINESS: 'layakkah menerima tugas?' — memori terpasang, IPC hidup,
izin utuh; hidup tapi tidak siap = tampilkan DEGRADED, JANGAN rayu tugas.


=== PAGE 154 ===
Aplikasi web memisahkan /livez dan /readyz karena dua klaim itu berbeda secara KAUSAL: proses bisa
hidup sementara dependensinya mati, dan sebaliknya. Ruka hidup tapi kehilangan memori adalah
pengalaman terburuk bagi Bos — chat jalan, jawaban kosong, kenangan hilang diam-diam. Pemisahan ini
membuat tray tidak pernah berbohong hijau saat memori mati, dan supervisor tidak membunuh proses
yang sehat hanya karena satu komponen sedang menyiapkan diri.

@dataclass
class RuntimeHealth:
    """Snapshot kesehatan — dibangun ulang tiap putaran, tak dipercaya
    lebih tua dari heartbeat_timeout."""
    liveness: bool = False
    readiness: bool = False
    state: RuntimeStatus = RuntimeStatus.OFFLINE
    components: dict[str, Component] = field(default_factory=dict)
    checked_at: float = field(default_factory=time.time)
    def set(self, name: str, status: ComponentStatus,
            detail: str = "", latency_ms: float | None = None
            ) -> None:
        self.components[name] = Component(name, status, detail,
                                          latency_ms)
    def _all(self, want: ComponentStatus) -> bool:
        return bool(self.components) and all(
            c.status == want for c in self.components.values())
    def evaluate(self, fsm: RuntimeStateMachine,
                 heartbeat_fresh: bool = True) -> RuntimeHealth:
        """Hitung ulang liveness/readiness dari komponen + status.
        Liveness  = denyut segar DAN minimal satu komponen hidup.
        Readiness = status mesin operational DAN semua komponen OK.
        Keduanya INDEPENDEN — itulah inti pemisahannya.
        """
        self.state = fsm.state
        self.liveness = heartbeat_fresh and any(
            c.status != ComponentStatus.DOWN
            for c in self.components.values()) if self.components \
            else heartbeat_fresh
        self.readiness = fsm.is_operational() and self._all(
            ComponentStatus.OK)
        self.checked_at = time.time()
        return self
    def snapshot(self) -> dict:
        return {
            "liveness": self.liveness,
