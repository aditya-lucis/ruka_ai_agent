23.1 WHY — dosa C:\Users dan mengapa %LOCALAPPDATA%
Menulis jalur pengguna DI DALAM KODE adalah jangkar yang menenggelamkan data saat nama
pengguna berubah, profil dipindah, atau mesin kedua tiba. Aturannya satu: jalur diselesaikan SAAT
RUNTIME dari lingkungan — lalu dipenjara.
Dosa kecil itu paling sering berujung insiden karena tiga sifatnya: ia BERHASUL di mesin pertama (lalu
lolos review), ia GAGAL di mesin kedua (lalu dipatch terburu-buru dengan hardcode baru), dan ia
MERUSAK saat profil berpindah (lalu data hilang tanpa jejak). Volume ini menutup kategori itu dengan
satu kelas yang menyelesaikan ALAMAT dari lingkungan dan satu metode yang MENJARA setiap
akses — berkas boleh hidup di mana pun Windows memutuskan profile-nya, kode tidak pernah tahu dan
tidak perlu tahu.
Mengapa LOCALAPPDATA, bukan APPDATA (Roaming) atau Program Files? Roaming disinkronkan
lintas mesin oleh domain — menyeret ruka.db yang tumbuh melintasi jaringan adalah keputusan yang
menyesal dikemudian; memori Ruka milik MESIN ini. Program Files milik installer dan butuh elevasi
admin untuk ditulis — agen single-user tidak berhak memaksa UAC untuk file log. LOCALAPPDATA:
per-pengguna, tanpa admin, tanpa sinkronisasi diam-diam — ruang yang tepat untuk penghuni. (Chrome,
VS Code, dan Spotify sampai ke kesimpulan yang sama; kita tidak menemukan kembali roda, kita

  reconnecting: 'tray-degraded.png',

  connected: 'Ruka siap',

    this.tray = new Tray(this.icon('tray-offline.png'));

    this.rebuild();

    if (!this.tray) { return; }
    this.tray.setImage(this.icon(STATE_ICON[s]));
    this.tray.setToolTip(`RUKA — ${STATE_LABEL[s]}`);

    if (!this.tray) { return; }
    const label = STATE_LABEL[this.state];
    this.tray.setContextMenu(Menu.buildFromTemplate([

      { type: 'separator' },

          // membuka jendela diagnostik (boot report, health, log)
          require('./main').toggleWindow();
        } },
      { type: 'separator' },
      { label: 'Keluar', click: () => app.quit() },
    ]));
  }
  destroy(): void {
    this.tray?.destroy();
    this.tray = null;
  }
}
