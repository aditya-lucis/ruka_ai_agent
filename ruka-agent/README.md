## ⚡ PERINTAH CEPAT KETERJAGAAN (QUICKSTART)

### 1. Bangkitkan Ekosistem utuh (GUI Desktop + Kernel + Brain)
Dari root direktori repositori:
```powershell
.\run_noctis.bat
```

### 2. Jalankan Perintah CLI Langsung
```powershell
# Sapaan pagi dan cek status kesehatan organ
python cli.py --status

# Tanya atau instruksikan Ruka dari terminal
python cli.py "Selamat pagi Ruka, periksa status proyek dan berikan ringkasannya"
```

### 3. Jalankan Pengujian Kognisi Mandiri (683 Tests, Rp 0)
```powershell
pytest
```

### 4. Jalankan Evaluasi Final Boss (Boss 11 Evaluator)
```powershell
python src/noctis_final_eval.py
```
